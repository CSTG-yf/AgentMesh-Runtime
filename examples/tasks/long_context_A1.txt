Context block: The system must compare a plain text collaboration baseline with a structured protocol collaboration mode. The structured mode must use agent handshakes, capability discovery, protocol mapping, StateRef handoff, non-text embedding states, shared memory, and reproducible benchmark metrics. The same task should be processed by planner, retriever, executor, and summarizer agents. The output should identify mandatory requirements, optional bonus requirements, measurable evidence, and delivery risks.
